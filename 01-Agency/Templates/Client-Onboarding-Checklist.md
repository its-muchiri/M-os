# Client Onboarding Checklist Template

## Pre-Engagement
- [ ] Signed Master Services Agreement (MSA)
- [ ] Signed Statement of Work (SOW) for initial project
- [ ] Initial deposit invoice sent
- [ ] Initial deposit received (___%)
- [ ] NDA executed (if required)

## Client Information Collection
- [ ] Primary contact name, email, phone
- [ ] Secondary contacts (technical, billing, decision-makers)
- [ ] Company legal name, address, tax ID
- [ ] Billing contact & invoicing requirements
- [ ] Preferred communication channels & cadence
- [ ] Timezone & business hours

## Access & Credentials
- [ ] Domain registrar access (or delegation instructions)
- [ ] DNS management access
- [ ] Current hosting/analytics access (Google Analytics, Search Console)
- [ ] Social media accounts
- [ ] Email marketing platform
- [ ] CRM access
- [ ] Design assets (logo files, brand guidelines, photography)
- [ ] Existing content inventory

## Technical Setup
- [ ] GitHub repository created/access granted
- [ ] Vercel/Netlify team access
- [ ] CMS project created (Sanity/Contentful/Strapi)
- [ ] Stripe/Payment processor account connected
- [ ] Monitoring/alerting configured (Sentry, Vercel Analytics)
- [ ] Staging environment deployed
- [ ] CI/CD pipeline configured

## Project Initialization
- [ ] Project folder created in `06-Projects/Active/`
- [ ] Client record created in `02-Clients/Active/`
- [ ] Project README.md with scope, timeline, team
- [ ] Requirements document drafted
- [ ] Task breakdown created in tasks.md
- [ ] Risk register initialized
- [ ] Decision log entry for project initiation

## Kickoff Meeting
- [ ] Scheduled (date/time)
- [ ] Agenda distributed
- [ ] Stakeholders invited
- [ ] Meeting notes template ready
- [ ] Action items captured

## Documentation Handoff
- [ ] Client added to relevant Obsidian vault sections
- [ ] Communication protocol documented
- [ ] Escalation path confirmed
- [ ] Success metrics agreed
- [ ] First sprint planned

## Post-Kickoff (First Week)
- [ ] Daily standups established
- [ ] Weekly sync scheduled
- [ ] First sprint backlog prioritized
- [ ] Blockers identified and assigned
- [ ] Client homework assigned (content, assets, approvals)

---

## Usage

Copy this template to `02-Clients/Active/[Client-Name]/Onboarding-Checklist.md` and check off items as completed.
