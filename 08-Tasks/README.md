# 08-Tasks

Task management with simple Markdown checkboxes.

## Structure

| Folder | Purpose |
|---|---|
| [[08-Tasks/Today/README|Today]] | Tasks for today |
| [[08-Tasks/This-Week/README|This-Week]] | Tasks for this week |
| [[08-Tasks/Backlog/README|Backlog]] | Tasks with no urgency |
| [[08-Tasks/Completed/README|Completed]] | Done tasks (archive) |

## Task Format

```markdown
- [ ] Task description [[link-to-project]] #tag
- [x] Completed task
```

## Rules

- Tasks link to [[02-Clients/README|clients]], [[06-Projects/README|projects]], [[03-Marketing/Campaigns/README|campaigns]], and [[07-AI-Agents/README|agents]].
- Move completed tasks to [[08-Tasks/Completed/README|Completed]].
