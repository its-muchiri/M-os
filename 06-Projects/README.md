# 06-Projects

Project management hub.

## Structure

| Folder | Purpose |
|---|---|
| [[06-Projects/Active/README|Active]] | Currently running projects |
| [[06-Projects/Planned/README|Planned]] | Projects in planning |
| [[06-Projects/Completed/README|Completed]] | Finished projects |
| [[06-Projects/Templates/README|Templates]] | Project templates |

## Rules

- One folder per project under Active/Planned/Completed.
- Each project folder contains: README.md, requirements.md, tasks.md, decisions.md, status.md, documentation.md.
- Projects link to [[02-Clients/README|clients]] and [[08-Tasks/README|tasks]].
